    Everything above came from a REST API over partitioned PostgreSQL. This page is a snapshot of it, because the deployment runs on a finite credit balance and is torn down on 2026-10-19 — so the charts keep working and the links below stop.

    Seven routes

    Three data endpoints, three analytics endpoints, one health check. Every link opens the live service while it is up.

      Keyset pagination, not OFFSET

      A page carries a cursor holding the sort key of its last row. The next page resumes from that key, so the cost of a page does not grow with how deep it is — about 1,900× faster than OFFSET a million rows in.

      One error shape

      Every refusal the application produces is an error object with code, message and detail. code is a closed set of five; detail.reason is what separates two refusals that share one code — the last two below both read invalid_range.

      The generated document

      Generated from the routes themselves and served at /openapi.json, with no CDN in the path. The two zeros are a known gap, documented rather than quietly fixed: the deployed image is pinned by digest, so adding them would publish a document the running service does not serve.
